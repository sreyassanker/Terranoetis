REST & WebSocket API

Platform v3.0.0 Docs v3.0.0 Last reviewed 2026-09-08 VERIFIED BY CODE INSPECTION ONLY (endpoint map read from route registrations; complete list in API.md)

Full description (prose, source of truth): API.md — the full endpoint table (source of truth)

On this page

  • Endpoint groups
  • Realtime transports

The API is Express 4 mounted at /api with JWT bearer auth (RBAC via authGuard/requireRole), in-process IP + per-user rate limiting, zod validation and a canonical {error:{code,message}} envelope. A public allow-list covers health/metrics/config/OpenAPI plus the read-only live-data routes (300 req/min/IP); everything else requires a token. server/index.ts:373-487

Route registrations (measured)
371 handler registrations (app.get/post/put/delete + router verbs) under server/ — grep count 2026-09-08; API.md headline “360+” is consistent
Auth
JWT TTL 1 h prod / 1 d dev · scrypt (N=16384, r=8, p=1) · login 5/15 min + 10-attempt lockout (HTTP 423)
Errors
400 validation · 401 token · 403 role · 404 · 409 job-not-ready · 413 body-too-large · 423 locked · 429 limited · 500
OpenAPI
GET /api/openapi.json (generated) + /api/docs UI
