Supported platforms & download packages

Recommended · arm64

macOS (Apple Silicon)

Native Mach-O 64-bit arm64 binary compiled for Apple Silicon (M1/M2/M3/M4). Runs on macOS 11.0 (Big Sur) and newer, including macOS Sonoma and Sequoia.

Download .app (ZIP · 50 MB) Download .dmg (Installer · 52 MB)
Windows x64

Windows

Desktop build configuration via Tauri v2 with WiX (.msi) and NSIS (.exe) packaging configured in the repository CI release workflow.

View Release Assets on GitHub ↗ Run Locally via Node.js 20+ →
Can also be compiled directly from source with npm run tauri:build on Windows with Rust and MSVC C++ Build Tools installed.
Linux x86_64

Linux

Stand-alone AppImage and Debian (.deb) desktop configurations using WebKit2GTK-4.1, plus standard containerized deployment.

View Release Assets on GitHub ↗ Deployment Stack Guide →
Build native packages locally on Ubuntu/Debian using sudo apt install libwebkit2gtk-4.1-dev && npm run tauri:build.
